Completed Projects

Public, version-controlled, and documented end to end.

DoneRNA-seq Differential Expression Pipeline

Snakemake workflow (FastQC, Trimmomatic, STAR, DESeq2, clusterProfiler GSEA) run end to end on public airway dexamethasone data (GEO GSE52778), scoped to three chromosomes so it runs on a laptop.

Result: 108 differentially expressed genes (61 up, 47 down); known dexamethasone genes DUSP1, PER1, and FKBP5 are all strongly induced. Honest caveat: scoped to three chromosomes, so the 21 to 24% unique mapping rate reflects whole genome reads against a partial reference.

DoneMulti-Omics Integration Capstone

DIABLO (mixOmics) integration of real, matched TCGA breast cancer data: mRNA expression, miRNA expression, and protein (RPPA), measured on the same patients, to predict molecular subtype.

Result: mRNA alone reaches 98.6% test accuracy; the 3 block integrated model reaches 94.3%, predicting on test samples missing the protein block entirely. Honest caveat: integration did not beat the single best block here, its real value is staying accurate despite a missing omics layer.

DoneGut Microbiome Diversity Analysis

DADA2 ASV inference, SILVA taxonomy, and phyloseq/vegan diversity analysis on real paired-end 16S rRNA data from mouse fecal samples, comparing community diversity and composition early versus late post weaning.

Result: PERMANOVA finds a significant community composition shift (R squared 0.430, p = 0.001) despite no significant difference in alpha diversity. ANCOM-BC2 finds 9 genera significantly differentially abundant between time points.

DoneBiomedical ML Classification Pipeline

Two part scikit-learn benchmark: Random Forest, Logistic Regression, and SVM on the tutorial level Wisconsin dataset, then the same leakage-free discipline on real TCGA pan cancer RNA-seq data (801 samples, 20,531 genes).

Result: 98.3% test accuracy on Wisconsin; 99.4% classifying 5 real cancer types from TCGA. Honest caveat: that accuracy is high because tissue of origin separates almost linearly in bulk RNA-seq, not because the task is clinically hard.
